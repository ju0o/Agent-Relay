# WBS-3 — OpenCode command adapter (implementation spec; from issue #6 + WBS-0 evidence; PM-authored)

Reuse `src/integrations/opencode/client.ts` conventions (loopback http, `GET /session` scoping) and add `src/integrations/opencode/command-adapter.ts` implementing `RoleRuntimeAdapter` (WBS-2) against the running `opencode serve`:
- Config: `{ baseUrl: 'http://127.0.0.1:4111', passwordFile: '~/.config/agent-relay/opencode-server.pass' (Basic auth user `opencode`), defaultModel: { providerID, modelID } }`. Never log the password; never call `/config/providers` (it leaks provider keys).
- Endpoints (proven in WBS-0): `GET /global/health`; `POST /session {title, model?}` → `{id}`; `POST /session/{id}/message {model:{providerID,modelID}, tools:{}, parts:[{type:'text',text}]}` → assistant message `{info:{role,providerID,modelID,tokens,cost,error?}, parts:[{type:'text',text}]}`; `GET /session/{id}/message` (history); use `tools: {}` for the PM role (read-only: the PM runtime must never mutate the workspace); optional `system` for the role prompt.
- Capabilities: persistentSession ✓, structuredInput ✓ (text), structuredOutput ✓ (caller-parsed), readWorkspace ✓ (via prompt context only, tools off), writeWorkspace ✗, shell ✗, subscriptionAuth = (auth list shows an oauth provider) else false, freeTier ✓ (opencode/*-free models).
- `authMode()`: derive from `opencode auth list` output or `GET /provider` (non-secret fields only): 'existing-plan-key' for opencode-go, 'oauth-subscription' if an OpenAI OAuth provider exists, 'free' when the selected model is `opencode/*-free`.
- Session policy: `persistent` → durable session id in role-sessions bookkeeping; `resume` = verify `GET /session/{id}/message` works; if the server is down → health false → caller marks BLOCKED (no paid fallback).
- Structured collection: `collect` returns the assistant text; WBS-5/8 parse `PM_TASK_DECISION v1` / `PM_JUDGMENT v1` from a fenced block; invalid → INVALID_STRUCTURED_OUTPUT (no canonical mutation).
- Proof script `scripts/wbs3-proof.mjs`: ensureSession(pm) → send prompt A → collect → send prompt B referencing A → collect (continuity) → simulate Relay restart (new process) → resume same session → collect history; print non-secret evidence JSON. Run it against the live loopback server with the FREE model by default (`opencode/nemotron-3.5-lightning-free`) so certification costs 0; allow `--model provider/model` override.
- Tests (test/opencode-command-adapter.test.mjs): unit tests against a tiny in-process fake HTTP server implementing the 4 endpoints (no real OpenCode needed): session create/reuse, send/collect, restart-resume, 401 → health false, invalid JSON → error mapping. Plus the proof script's evidence file from a real run committed as docs/WBS3_EVIDENCE.md (non-secret).
Rules: additive; do not modify client.ts semantics; no OpenAI API; password from file only.
